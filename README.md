# CompMechBook

**From Vectors to Atoms: Computational Mechanics** — a narrative mdBook covering linear algebra through functional analysis, FEM, FVM, dislocation dynamics, molecular dynamics, and DFT.

Content is synthesized from the author's [Writings](https://hanfengzhai.github.io/note.html) (course notes and research summaries), organized in the style of [Functional Analysis Notes (THU_BFA)](https://github.com/duskmoon314/THU_BFA).

## Quick start

```bash
# Install mdBook: https://github.com/rust-lang/mdBook/releases
# Optional: mdbook-katex for KaTeX math

mdbook build
mdbook serve   # http://localhost:3000
```

Output is written to `book/`.
